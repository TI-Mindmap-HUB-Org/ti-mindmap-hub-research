# Contributing to TI Mindmap HUB

Thank you for your interest in contributing to TI Mindmap HUB! This document provides guidelines for contributing to this research and documentation repository.

For the full contributing guide with detailed instructions, see [docs/community/contributing.md](docs/community/contributing.md).

## Quick Start

1. **Fork** this repository
2. **Create a branch** (`git checkout -b docs/your-improvement`)
3. **Make changes** following the [Docs Style Guide](docs/community/style-guide.md)
4. **Test locally** with `mkdocs serve` (requires `pip install -r requirements.txt`)
5. **Commit** using conventional format: `docs: your change description`
6. **Open a Pull Request**

## Ways to Contribute

- **Documentation** — Fix typos, clarify content, add examples
- **STIX examples** — Contribute sanitized STIX bundles
- **Feedback** — Report incorrect outputs or extraction errors
- **Source suggestions** — Recommend new OSINT sources
- **Academic collaboration** — Research partnerships and thesis supervision

## Code of Conduct

All participants are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Not In Scope

- Core application code (maintained privately)
- Feature requests requiring platform code changes
- Operational support requests
