# Security & Privacy

TI Mindmap HUB takes security seriously. This page covers vulnerability disclosure, security considerations, and privacy statements.

---

## Vulnerability Disclosure

If you discover a security vulnerability, please report it responsibly.

**Email:** [info@ti-mindmap-hub.com](mailto:info@ti-mindmap-hub.com)

**Subject line:** `[SECURITY] Brief description`

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fixes (optional)

### Response Timeline

| Stage | Timeframe |
|-------|-----------|
| Acknowledgment | Within 48 hours |
| Initial assessment | Within 7 days |
| Resolution | Depends on severity |

### Scope

This policy applies to:

- The TI Mindmap HUB web application (ti-mindmap-hub.com)
- APIs and backend services
- The MCP server (mcp.ti-mindmap-hub.com)
- This public repository

### Out of Scope

- Third-party services and infrastructure providers
- Social engineering attacks
- Physical security
- Denial-of-service attacks

### Recognition

We appreciate security researchers who help keep TI Mindmap HUB secure. With your permission, we will acknowledge your contribution publicly.

## AI-Generated Content

All content on the platform is AI-generated and may contain:

- Incorrect information or fabricated details
- False positives in IOC extraction
- Misattributed threat actors or malware families

!!! danger "Critical Rule"
    **Never use platform outputs for critical security decisions without independent verification.**

## Data Handling

- User data is stored on managed cloud infrastructure
- Authentication uses industry-standard identity services
- No user data is used for AI model training
- See the [Privacy Policy](https://ti-mindmap-hub.com/privacy) on the main site for full details
