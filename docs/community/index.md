# Community

TI Mindmap HUB is an open research project that welcomes contributions from security practitioners, researchers, and documentation writers.

---

## Ways to Contribute

| Type | Description |
|------|-------------|
| **Feedback** | Report incorrect outputs, false positives, or extraction errors |
| **Documentation** | Fix typos, clarify explanations, add examples |
| **STIX examples** | Contribute sanitized STIX bundles or edge-case examples |
| **Source suggestions** | Recommend new OSINT sources for monitoring |
| **Academic collaboration** | Joint research, thesis supervision, dataset sharing |

See the full [Contributing Guide](contributing.md) for details.

---

## Communication Channels

| Channel | Use For |
|---------|---------|
| [GitHub Issues](https://github.com/TI-Mindmap-HUB-Org/ti-mindmap-hub-research/issues) | Bug reports, docs improvements, feature requests |
| [Email](mailto:info@ti-mindmap-hub.com) | Academic collaboration, security disclosures, general questions |
| [Twitter/X](https://x.com/ti_mindmap_hub) | Announcements and updates |

## What We're Not Looking For

To set clear expectations:

- Core application code changes (app code is maintained privately)
- Feature requests requiring code changes to the platform
- Operational support requests
- Commercial partnership proposals (use email instead)
